# cozmo_clone — 設計の前提

Anki Cozmo（2016）のクローン。段階 1（ヒアリング）の結果。

## 目的

卓上で動く小型キャラクターロボット。走行し、リフトアームでキューブを操作し、
ヘッドチルトと顔ディスプレイで表情を作る。映像は母艦（PC / スマホ）へ WiFi で飛ばし、
顔認識・マーカー認識は母艦側で行う。

使用環境: **屋内・卓上。可搬（手で持ち運ぶ）。防水・防塵は不要。**

## ヒアリングで確定した事項

| 項目 | 決定 |
|---|---|
| 再現範囲 | **フル再現・4自由度**（左右走行 + リフトアーム + ヘッドチルト + 顔ディスプレイ） |
| 外形サイズ | **実物の約 1.5 倍、全長 約 150 mm** |
| 駆動方式 | **車輪**（キャタピラは不採用） |
| 全 4 軸 | **DYNAMIXEL XL330 シリーズで統一** |
| 車輪 | **タミヤ No.145 ナロータイヤ（58 mm 径）** を流用 |
| 電源 | **NiMH 4.8V パック**（XL330 バスへ直結、降圧不要） |
| 制御系 | **M5Stack 系で統一** |
| 画像処理 | **母艦（PC / スマホ）に飛ばす**。ロボット側は映像送信とモータ制御に専念 |

実物大 100 mm を選ばなかった理由: 4自由度ぶんの駆動系と電源を市販部品で 100 mm に
収めるのは成立しにくい。1.5 倍にすることで見た目の雰囲気を保ちつつ設計を成立させる。

## pen_robo からの流用

本機は既存の pen_robo（ホイール脚ロボット）と**電装・駆動系がほぼ同一**になる。
調査済みの資産をそのまま使えるため、寸法調査の手戻りが小さい。

| 流用するもの | 所在 |
|---|---|
| XL330 の実形状モデル（軸原点・ホーン穴 P.C.D φ12） | `hwlib/parts/xl330.py` |
| タミヤ 70145 の実形状モデル（外径 58 / リム 42 / 3穴 PCD 20） | `hwlib/parts/tamiya_wheel.py` |
| 公式図面 | `datasheets/xl330/`、`datasheets/tamiya_70145/` |
| **XL330 → タミヤホイール 変換ハブ** | `projects/pen_robo_wheel_hub/` |
| サーボ I/F 基板・NiMH パックの選定 | `pen_robo/wheel_leg_robot_hw_spec.md` §7 |

**変換ハブは新規設計せず、pen_robo_wheel_hub の成果物をそのまま使う。**
ただし同ハブには `wheel_boss_wall`（ホイールのビス穴部の壁厚）が provisional として
残っているため、印刷前の実測は本機でも必要。

## 構成

```
[母艦 PC/スマホ] ←WiFi(MJPEG)── [Unit CamS3: 映像配信専用(独立)]
       └──WiFi(操縦/認識結果 UDP)──→ [AtomS3R]
                                        │ ESP32-S3 + BMI270 IMU
                                        │ UART(Grove) ── [B-SKY Lab XL330 I/F 基板(MAX3485)]
                                        │                  └ DYNAMIXEL TTL バス(デイジーチェーン)
                                        │                      ├ XL330-M077 x2（車輪 L/R）
                                        │                      ├ XL330-M288 x1（リフトアーム）
                                        │                      └ XL330-M288 x1（ヘッドチルト）
                                        ├ I2C(Grove) ── [Unit OLED 1.3": 顔]
                                        └ 電源: NiMH 4.8V ─┬─ XL330 バス(直結)
                                                           └─ 5V DC-DC ── AtomS3R / Unit CamS3
```

### 軸の割り当て

| 軸 | 型番 | 制御モード | 根拠 |
|---|---|---|---|
| 車輪 L/R | XL330-**M077**-T | 速度制御 | 無負荷 383 rpm。車輪径 58 mm で最高 1.16 m/s |
| リフトアーム | XL330-**M288**-T | 位置制御 + 電流制限 | ストール 0.52 N·m。高トルク側でアームを保持する |
| ヘッドチルト | XL330-**M288**-T | 位置制御 | 低速のほうが表情の動きとして自然 |

M077 と M288 はケース・ホーン・取付穴が共通（20 x 34 x 26 mm、18 g）なので、
**CAD 上は 4 軸とも同一形状として扱える。**

### 部位の割り当て

| 部位 | 搭載物 | 意図 |
|---|---|---|
| 頭（チルトする） | Unit OLED（顔）、Unit CamS3（カメラ） | Grove 線だけが首を通る。重量物を頭に置かない |
| 胴体上部 | ヘッドチルト用 XL330、AtomS3R、I/F 基板 | |
| 胴体中央 | NiMH パック（57 x 50 x 16 mm） | 最も重い部品（約 100 g）。低く中央に置いて重心を下げる |
| 胴体下部 | 車輪用 XL330 x2 | 出力軸を左右方向に向ける。車輪は外側 |
| 胴体前方 | リフトアーム用 XL330、平行リンク | Cozmo 同様、アームは前方へ張り出す |

### 部品選定の根拠

- **顔 = M5Stack Unit OLED 1.3インチ（128x64 モノクロ）**
  実物 Cozmo の顔も 128x64 のモノクロ OLED。解像度・表現とも最も忠実な選択肢になる。
  Grove の I2C 4 線だけで駆動でき、チルト関節を通す配線が最小になる。
- **制御 = AtomS3R**
  24 x 24 x 12.9 mm と小さく、ESP32-S3 の WiFi と BMI270 IMU を内蔵する。
  IMU で持ち上げ検知・転倒検知ができる（Cozmo の "pickup" 反応に相当）。
- **サーボ I/F = B-SKY Lab XL330 インターフェース基板 v2.0**
  MAX3485 による半二重 TTL 変換。50 x 20 mm と小さい。設計データが MIT で公開されており、
  在庫切れでも自作できる。pen_robo と共通。
- **カメラ = Unit CamS3**
  独立した WiFi カメラとして映像送信に専念させ、制御ループを妨げない
  （pen_robo の M5Camera と同じ考え方）。

### 検討したが採らなかった案

- **キャタピラ駆動**: 見た目は実物に近いが、トラック・スプロケットの調達か自作が必要で、
  寸法が確定しないと骨格が決まらない。XL330 + 既存の変換ハブなら調査済み資産で進められる。
- **AtomS3R を頭に置き、顔として使う**: 0.85 インチ LCD で顔を作れるが、制御中枢が首の先に
  来るため配線が太くなる。また画面が正方形で Cozmo の横長の顔と合わない。
- **リフト・ヘッドをマイクロサーボにする**: 安価だが TTL と PWM の 2 系統になり基板が増える。
  また PWM サーボはアームを上げた姿勢の保持で発熱する。XL330 なら電流制御で解決できる。

## 外部インターフェース

- **USB-C x2**: AtomS3R（書き込み）、Unit CamS3（書き込み）。**ケースを開けずに届くこと**
- **電源スイッチ**: 胴体側面または底面。XL330 バスへの給電を切る
- **充電コネクタ**: NiMH パックを外して充電する運用とし、パックは工具レスで取り出せること
- **カメラ窓**: 頭部前面
- **顔ディスプレイ窓**: 頭部前面。OLED の有効表示エリアだけを露出させる

## 未確定事項（段階 3 で詰める）

1. **AtomS3R の Grove ポートから I/F 基板を駆動できるか**
   I/F 基板は M5Stack Core2 の PORT.C（UART G13/G14）想定で設計されている。
   AtomS3R の Grove ポートを UART に割り当てれば電気的には成立するはずだが、
   コネクタ形状（基板側 J1 は JST PH）と結線を確認する必要がある。
   なお GitHub の README と pen_robo 仕様書 §11.3 で J1/J2/J3 の割り当ての記述が食い違っている。
   **配線を作る前に現物で確認すること。**
2. **制御系の 5V をどう作るか**
   NiMH 4.8V から昇圧するか、AtomS3R の 5V 入力が 4.8V 直結で動くか。
   サーボの突入電流による電圧降下がロジックに回らないよう、系統を分けるか大容量コンデンサを入れる。
3. **第 3 の接地点**（下記リスク参照）
4. Unit OLED / AtomS3R / Unit CamS3 の正確な外形・取付穴・有効表示エリア

## この機体のリスク

- **2 輪では自立しない。** 実物 Cozmo はキャタピラの長い接地面で前後に倒れないが、
  本機は車輪 2 個なので**第 3 の接地点（キャスタまたはスキッド）が必須**。
  さらにリフトアームでキューブを持ち上げると重心が前に移るため、
  **前後両方に接地点を置くか、車輪を前後方向の中央より前に寄せる**必要がある。段階 4 で決める。
- **卓上運用＝落下**: Cozmo は 4 個の崖センサで机の端を検知する。これが無いと初回で落ちる。
  崖センサは必須部品として BOM に入れる
- **首を通る配線**: チルト可動域ぶんのたるみ（サービスループ）を確保しないと断線する。
  配線が占める体積を BOM の `wiring` に体積付きで計上する
- **XL330 は樹脂ギヤ**: 転倒や机からの落下で欠けやすい。崖センサと転倒検知（IMU）で守る
- **サイズが XL330 に律速される**: XL330 は 20 x 34 x 26 mm。4 個で体積を食うため、
  全長 150 mm が本当に成立するかは段階 4 のレイアウトで検証する。
  収まらない場合はユーザに全長の見直しを相談する
- **NiMH パックが大きい**: 57 x 50 x 16 mm・約 100 g は全長 150 mm の機体に対して大きい。
  胴体の断面がこれで決まる可能性が高い
